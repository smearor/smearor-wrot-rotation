fn fill_aspect(solved: Size<f64>, natural: AspectRatio) -> AspectRatio
Expand description

The child aspect for FillStrategy::Clamp: the exact solve’s aspect solved.x / solved.y, clamped to a bounded distortion range around the child’s natural aspect. Covering with the exact aspect reproduces unrotated_bounds wherever the solve is feasible (both axes tight at the same value), so the resulting allocation is continuous across the whole rotation. Inside the infeasible band the solve’s aspect sweeps ∞ → 0 and the clamp morphs the child bar-to-square-to-bar without jumps; a degenerate NaN (square viewport at 45° + k·90°) falls back to the natural aspect.
